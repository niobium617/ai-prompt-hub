# AI Prompt Hub 🚀

> [简体中文](./README.md) | English

An AI prompt sharing & community platform — combining a prompt library, AI skill tutorials, online tools, and community discussions in one place.

> 📌 This is a **personal learning project**. No online service is provided; it is intended for local deployment, learning, and code reference only. Please do not deploy it as a public service without permission.

## ✨ Features

| Module | Description |
|--------|-------------|
| **User System** | Email/username login, email verification-code login, WeChat Mini Program login, JWT auth, change password |
| **Prompt Library** | Publish / review / search / filter by category & difficulty / sort / pagination, example images |
| **Community** | Favorites, ratings, comments & replies, likes, notification center |
| **Draft System** | Derive private drafts from public prompts, side-by-side original/draft editing |
| **AI Tools** | Prompt generator, prompt optimizer (real API with Mock fallback) |
| **Tutorials & Tips** | 12 AI tool tutorials, 12 prompt engineering tips |
| **Admin Dashboard** | Content review, published-content management, user management (ban/roles), statistics |
| **Dev Mode** | Site badge indicator, restricts write operations to test accounts only — handy while debugging deployments |

## 🚀 Quick Start

### Requirements

- Node.js >= 18
- pnpm >= 8

> Local development uses SQLite — no Docker/MySQL required.

### Install & Run

```bash
# 1. Install dependencies
pnpm install

# 2. Configure environment variables
cp .env.example packages/server/.env

# 3. Initialize the database (create tables + seed data)
cd packages/server
npx prisma db push
npx ts-node prisma/seed.ts
cd ../..

# 4. Start the backend (http://localhost:3000)
pnpm dev:server

# 5. Start the frontend (http://localhost:5173)
pnpm dev:web
```

### Access

- Frontend: http://localhost:5173
- API docs (Swagger): http://localhost:3000/api/docs
- Database GUI: `pnpm db:studio`

### Test Accounts (local dev)

| Role | Email |
|------|-------|
| Admin | admin@prompt-hub.local |
| Regular user | test@prompt-hub.local |

> Local initial passwords are randomly generated by the seed script and printed to the terminal (see `packages/server/prisma/seed.ts`). Production uses separate strong passwords — never reuse local ones.

## ⚙️ Environment Variables

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | Database connection (local SQLite / production MySQL) |
| `JWT_ACCESS_SECRET` / `JWT_REFRESH_SECRET` | JWT secrets (required in production — startup is refused if missing) |
| `LLM_API_KEY` / `LLM_API_BASE_URL` / `LLM_MODEL` | AI generator configuration (falls back to Mock if unset) |
| `SMTP_HOST` / `SMTP_USER` / `SMTP_PASS` | Email verification codes (when unconfigured in production, the feature refuses service instead of leaking codes; codes are only printed in local dev mode) |
| `WECHAT_APP_ID` / `WECHAT_APP_SECRET` | WeChat Mini Program login (login is refused in production when unset; mock is only available in local dev mode) |
| `DEV_MODE` | Dev mode switch (when `true`, write operations are restricted to test accounts) |
